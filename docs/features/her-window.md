# Her window - the transcript

Built 2026-11-03. Layout and look: [The Spread](the-spread.md) ([ADR 0024](../adr/0024-the-conversation-is-a-book-of-spreads.md)) - the conversation is a book read one spread at a time, folded to one page in her window; it replaced the timeline transcript of ADR 0016. What follows is how her words and a turn's parts are read and kept, which the book draws.

## What it does

- **Her words read as rich text.** Her replies, settled or still streaming, and a chore's brief in the main window all come through one door, `ui/Prose.tsx` over `ui/markup.ts`: a dependency-free reader of a markdown subset (paragraphs, line breaks, bold, italic, inline code, fenced code with a Copy button that copies the source exactly, bulleted and numbered lists, links, and `#` to `###` headings, each read as one bold line with no size scale because a chat column is not a document). Everything else stays literal text, and every string reaches the page as a React text node, so HTML or script in a reply is shown as characters and never runs. A link is not clickable: its words are shown with the true address beside them, because both are model-authored.
- **A reply streams in the order it was written.** Text runs, tool lines and cards stand in the order the stream delivered them (`LivePart[]` in `athena/store.ts`); a sentence written after a tool line comes after it. In the book a tool line is a receipt on the left page, her words, cards and report parts are the answer on the right, and each part keeps its moment (ADR 0024).
- **A settled turn keeps its parts.** The daemon stores an Athena turn's text runs, tool lines and cards in emitted order (`turns.parts`, the wire `Turn.parts`), and her window draws a reloaded turn through the same reducer (`addPart`) and renderer as the live one, so it looks the same before and after a reload. A turn stored before parts were kept shows as its words and first card, as before; a part this version does not know shows as a plain row, never nothing.
- **A comparative answer shows report parts.** In a project that keeps records she may answer a comparative or quantitative question with 1 to 3 parts of the report's own kit (`show_blocks`, [ADR 0022](../adr/0022-her-replies-show-report-parts-from-the-same-kit.md)): bound to the records, through the report's validation door, every figure computed by the daemon, each part full width with no pin. They stand in place among her words, a dropped part is said with its reason, and a settled turn keeps them with the figures they showed.
- **A streaming prefix renders stably.** An open code fence is already a code block, an unclosed `**` or `*` or backtick is styled as if closed at the tail, and a marker the next delta has yet to decide (a trailing `*`, or a bare `#` opening the last line) is held back; only the last block is re-read as words arrive. Settled text has no provisional reading: an unmatched marker there is literal.
- **New words fade in.** While she writes, each delta's words fade in once (opacity, `--dur-fast`), snapped to whole words; earlier words are never animated again, and nothing animates under calm motion, under reduced motion, or once the turn is done.

## Verified

`ui/markup.test.ts` (each construct, literal fallbacks, streaming prefixes, re-reading only the last block giving the same blocks as a full read), `ui/Prose.test.tsx` (elements, inert HTML, links, copy, stable prefixes, the reveal and its calm rule), `athena/App.test.tsx` (parts in streamed order, rich text and inert HTML settled and live, a turn drawn the same live and after a reload from stored parts, an old turn without parts, an unknown part), `main/chores/chores.test.tsx` (the brief through the same door), `tests/test_turn_parts.py` (the daemon keeps the parts in streamed order; an older database's turns read back unchanged), `tests/test_report_chat.py` (report parts: offered only with records, computed values, drops disclosed, kept with the turn, the simulated engine never calls it, an outside lease never sees it).

## Limits

- Not in the subset: headings deeper than `###`, tables, quotes, nested lists (an item indented up to three spaces joins the list above; deeper, it is a line of the item above), images. They show as their characters.
- The reveal snaps to spaces, so a script written without spaces fades in by delta, not by word.
- When to show report parts is taught in the tool's description, not yet measured against a labelled set of intents; the simulated engine never shows them.
